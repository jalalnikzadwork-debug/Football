# Sunday Football Club - Website

موقع إدارة نادي كرة القدم الأسبوعي - نظام كامل لإدارة المباريات والفرق والإحصائيات

## الميزات الرئيسية

### 1. تسجيل اللاعبين
- تسجيل الدخول برقم الهاتف (بدون بريد إلكتروني)
- رفع صورة شخصية
- اختيار مركزين كحد أقصى
- إدخال البيانات الأساسية (العمر، الوزن، الطول)

### 2. نظام الحضور
- تأكيد الحضور بنعم/لا
- حالة "معلق" حتى يرد اللاعب
- عرض عدد المؤكدين والمعلقين والرافضين
- عداد تنازلي للمباراة

### 3. نظام التقييم (مثل FIFA)
- **Base Overall (OVR)**: التقييم الأساسي للاعب
- **Potential (POT)**: الإمكانيات المستقبلية
- **Dynamic Overall**: يتغير تلقائياً بعد كل مباراة بناءً على الأداء

#### سمات اللاعب (Attributes):
- Pace (السرعة)
- Shooting (التسديد)
- Passing (التمرير)
- Dribbling (المراوغة)
- Defending (الدفاع)
- Physical (اللياقة البدنية)
- Goalkeeping (حراسة المرمى)

### 4. إحصائيات المباراة
بعد كل مباراة، يقوم المسؤول بتقييم كل لاعب:
- Goals (الأهداف)
- Assists (التمريرات الحاسمة)
- Chances Created (الفرص المصنعة)
- Shots (التسديدات)
- Passes (التمريرات)
- Pass Accuracy % (دقة التمرير)
- Dribbles (المراوغات)
- Tackles (الالتحامات)
- Interceptions (الاعتراضات)
- Fouls (الأخطاء)
- Saves (لحراس المرمى)
- Clean Sheet (لحراس المرمى)
- Goals Conceded (لحراس المرمى)
- Match Rating (1-10)
- Man of the Match (MOTM)

### 5. نظام اختيار الفرق
- رمي العملة عشوائياً لتحديد من يختار أولاً
- اختيار اللاعبين بالتناوب بين الكابتنين
- إمكانية تبديل اللاعبين بين الفرق
- عرض التشكيلة النهائية للجميع

### 6. إشعارات WhatsApp
- إرسال رسائل تذكير قبل 12 ساعة من المباراة
- رابط مباشر للموقع لتأكيد الحضور
- خيارات YES/NO واضحة

### 7. لوحة الإحصائيات
- ترتيب اللاعبين حسب:
  - الأهداف
  - التمريرات الحاسمة
  - التقييم
  - التقييم الديناميكي
  - جوائز أفضل لاعب
- تاريخ المباريات
- إحصائيات تفصيلية لكل لاعب

## كيفية الاستخدام

### للمسؤول (Admin):
1. أول شخص يسجل يصبح المسؤول تلقائياً
2. من صفحة Admin يمكن:
   - إدارة جميع اللاعبين
   - تعيين الكابتنين
   - تعديل سمات اللاعبين (OVR, POT, Attributes)
   - إنشاء المباريات
   - تقييم اللاعبين بعد كل مباراة
   - إرسال إشعارات WhatsApp

### للاعبين:
1. التسجيل برقم الهاتف
2. رفع صورة شخصية
3. تأكيد الحضور من صفحة Match Day
4. عرض الإحصائيات والترتيب
5. رؤية التشكيلة النهائية

### للكابتنين:
1. المشاركة في اختيار الفرق
2. رمي العملة لتحديد من يبدأ
3. اختيار اللاعبين بالتناوب
4. الموافقة على التشكيلة النهائية

## التثبيت والنشر

### المتطلبات:
- Node.js 18+
- npm أو yarn

### التثبيت:
```bash
npm install
```

### التشغيل المحلي:
```bash
npm run dev
```

### البناء للإنتاج:
```bash
npm run build
```

### النشر المجاني:

#### على Vercel:
1. ارفع المشروع على GitHub
2. اذهب إلى vercel.com
3. اربط المستودع
4. انقر Deploy

#### على Netlify:
1. ارفع مجلد `dist` بعد البناء
2. أو اربط مستودع GitHub للنشر التلقائي
